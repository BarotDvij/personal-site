# Roadmap

Everything planned for v1 and v2 (the arcade, character, museum, fly-over) is built. See `MASTER_CHECKLIST.md` for what is left.

## Rules for every game
- **Offline only.** No servers, no accounts, no leaderboards. The site stays static, free to run, and fast for any number of visitors.
- **Loaded on demand.** Each game is its own small file that downloads only when someone starts it. First load never gets heavier.
- **Inspired by, not copied.** Our own art, names, and sounds.
- **Credit the originals by name.** Each game gets a generic title plus a plain-text credit line. Names in plain text only: no logos, and nothing that suggests the game is official or endorsed.
